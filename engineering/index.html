01

UT Probe Holder — Magnetic Pipe Scanner

A spring-actuated, constant-force ultrasonic probe holder with magnetic mounting, for hands-free pipe scanning from 2″ NPS through to flat surfaces. Reverse-engineered from an existing design, then reworked for printability and field repair.

Ran FEA across PLA, PETG, ABS and PA6-CF to compare structural performance under spring loading, developed TPU gaskets for probe sealing and vibration damping, and made the architecture modular so components swap out to fit different probe sizes.

02

HVAC ESP Calculator

A Python/Tkinter desktop application that calculates external static pressure losses across multi-section duct systems — automating fitting-loss lookups, velocity checks and total system ESP, and replacing the manual spreadsheet workflow I was using daily.

Each fitting is picked from a tree of ASHRAE fitting types, so every loss coefficient traces back to a published fitting number. The run exports to Excel with the job and checker fields filled in. Packaged as a standalone executable and handed to colleagues.

  • Python
  • Tkinter
  • ASHRAE fittings
  • HVAC

03

Bridge Inspection Data Tools

A set of Excel tools, built with UserForms and VBA, for capturing bridge and sign-structure inspection measurements in the field and turning them into reports and inventories without retyping. Used across an inspection program of 350+ overhead sign structures.

Later reworked the measurement tool for a multi-year bridge inspection so that it keeps earlier years' readings, recalls each measurement location correctly, and cannot silently drop data — then handed it to a second user to stress-test before it was relied on.

  • Excel VBA
  • UserForms
  • Data validation
  • Inspection
